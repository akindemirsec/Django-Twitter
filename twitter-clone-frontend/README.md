# React frontend

See the [project README](../README.md) for backend setup, environment configuration,
features, and limitations.

From this directory, run `npm ci` and `npm start`. Open http://localhost:3000.
The API is expected at http://127.0.0.1:8000.

- `npm run build`: create a static bundle in `build/`.
- `npm test -- --watchAll=false`: run the frontend tests once.
